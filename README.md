# Artificial Intelligence Algorithms

A collection of Artificial Intelligence algorithms and problem-solving techniques implemented in Python using Jupyter Notebooks. This repository explores fundamental AI concepts including graph search, heuristic search, game-playing strategies, and optimization techniques.

## Features

### Search Algorithms

* Breadth First Search (BFS)
* Depth First Search (DFS)
* A* Search Algorithm
* Greedy Best-First Search
* BFS vs DFS Comparison

### Maze Solving

* Maze Solving using BFS
* Maze Solving using DFS

### Game Playing AI

* Minimax Algorithm
* Alpha-Beta Pruning
* Alpha-Beta Pruning with Heuristic Evaluation
* Tic-Tac-Toe AI

### Python for AI

* NumPy Fundamentals
* Pandas Fundamentals

## Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Google Colab
